音訊整理工具

蒐集測試音訊用的小工具：從 YouTube 下載指定區段存成 wav，以及檢查 / 整理資料夾裡音訊的格式與長度。改編自德育同學的 yt2wav - time.bat（一次貼一個連結、輸入開始與結束時間），這版加上選單、批量下載、資料夾檢查與設定記憶。

功能

功能說明
單筆下載貼一個連結，自己指定「第幾秒到第幾秒」
批量下載讀 TXT（一行一個連結），開始前只問一次「從第幾秒開始、抓幾秒」，全部統一
擋重複下載同一部影片（YouTube 影片 ID）在同一個儲存資料夾只下載一次
精準長度下載後用 ffmpeg 修成剛好指定的長度（多的截掉、不足補靜音），16-bit wav
檢查 / 整理資料夾掃描所有子資料夾，列出格式、長度不符的檔案，確認後才修改
設定記憶儲存位置、TXT 路徑、批量時間、整理規則都可以記住，下次直接沿用

安裝需求

  • Python 3（有 python 指令）
  • yt-dlp（含官方附加元件）：python -m pip install -U "yt-dlp[default]"
  • Deno（JavaScript 執行環境，YouTube 現在需要它）：winget install DenoLand.Deno，裝完重開視窗
  • ffmpeg（含 ffprobe），要加進系統 PATH

確認方式：在命令提示字元輸入 python -m yt_dlp --version 和 ffmpeg -version，兩個都印出版本號就可以了。

開始使用

雙擊 音訊工具.bat，會出現選單：

═══════ 音訊整理工具 ═══════
1. 檢查 / 整理資料夾（時長、格式）
2. 下載音樂
0. 離開
選擇 [1]：
  • 中括號 [...] 裡是預設值，直接按 Enter 就是用它
  • 資料夾、TXT 可以從檔案總管直接拖進黑色視窗，不用手打路徑
  • 按 Ctrl + C 中斷目前的工作，回到主選單

下載

選 2，再選單筆或批量，接著選儲存位置。

單筆

貼上連結：https://www.youtube.com/watch?v=xxxx
從第幾秒開始（例：35、1:15） [0]：1:00
到第幾秒結束（直接 Enter = 開始後 30 秒） [1:30.00]：1:10   ← 抓 1:00～1:10，共 10 秒

批量

先用記事本準備一個 TXT，一行一個連結：

# 這行是註解，會略過
https://www.youtube.com/watch?v=aaaa
https://www.youtube.com/watch?v=bbbb

https://www.youtube.com/watch?v=cccc

空行和 # 開頭的行會略過；連結後面多寫的字不會使用。執行時只問一次，所有連結都套用同一個區段：

全部從第幾秒開始（例：30、1:15） [0:30]：1:00
每段抓幾秒 [30.0]：（直接 Enter）
  讀到 3 個連結，全部從 1:00.00 開始抓 30 秒

建議音樂和語音分成兩個 TXT、分兩次下載，存到不同資料夾（例如 200音樂、200秘密）。

時間怎麼填

「從第幾秒開始」問的是：每部影片要從哪個時間點開始剪，就是 YouTube 進度條上看到的時間。

想從哪裡開始輸入
第 30 秒30 或 0:30
1 分 15 秒1:15
1 小時 2 分 3 秒1:02:03
用上次的設定直接按 Enter（用中括號裡的值）

怎麼選開始時間

  • 音樂：前奏通常比較安靜，建議跳過，例如從 1:00 開始，比較容易抓到副歌或主旋律
  • 語音：開頭常是片頭音樂或打招呼，建議從 0:30 或 1:00 開始
  • 影片如果比「開始時間 + 長度」還短，不足的部分會補靜音

檢查 / 整理資料夾

選 1，可以先修改目標設定，再拖入要檢查的資料夾。工具會先列出「預計更改清單」，按 y 之前不會動到任何檔案。

── 預計更改清單 ──  合格 362、要修改 21、太短 1、讀不到 0
  [修改] 皮卡丘\200秘密\bN3StB5t.wav  →  修剪 30.70 → 30 秒（保留中間）
  [修改] 皮卡丘\200音樂\xxx.mp3  →  轉檔 .mp3 → .wav
  [太短] 詹為真\200音樂\yyy.wav  →  太短 29.00 秒 → 不處理，只列出

確定照這個清單執行嗎？ (y/n) [n]：

可設定的目標：

設定選項預設
目標格式副檔名，例如 wavwav
目標時長秒數，±0.05 秒內算合格30
過長怎麼修剪保留中間 / 保留開頭保留中間
太短怎麼辦不處理只列出 / 移到「資料夾_太短」/ 刪除移到「資料夾_太短」
修改後直接覆蓋原檔 / 另存到「資料夾_整理後」直接覆蓋原檔
取樣率、聲道數值，0 = 不改不改

保留中間怎麼算：起點 =（原長 − 目標長度）÷ 2。例如 40 秒的檔案切第 5～35 秒。

限制與注意事項

  • 擋重複只看影片 ID：同一首歌如果是另一部影片（別人上傳的），工具擋不住；音樂、語音存在不同資料夾時，兩邊各有一份紀錄。
  • 批量時間是統一的：沒辦法替 TXT 裡個別的連結指定不同時間；要不同時間請用單筆下載。
  • 檔名用影片標題，Windows 不允許的字元（\ / : * ? " < > |）會換成 _。
  • 「直接覆蓋原檔」無法復原，轉檔時舊格式的原檔會被刪掉；不確定時先改成「另存到新資料夾」。
  • 下載出現 403 / ffmpeg exited：多半是 YouTube 改了機制，執行 python -m pip install -U "yt-dlp[default]" 更新後再試。
  • 下載出現 This video is not available：先用瀏覽器確認影片能播放；能播放的話，多半是缺 Deno 或解題腳本（見安裝需求）。
  • 這份 HTML 的流程圖需要網路（從 CDN 載入 Mermaid）；離線時只會顯示流程圖的原始碼。
